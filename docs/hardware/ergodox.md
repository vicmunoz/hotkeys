# Ergodox EZ

## Layout

- [Ergodox EZ layout](https://configure.zsa.io/ergodox-ez/layouts/aqqOo/latest/0)

## Role

Primary external keyboard. Uses a macOS-oriented layout.

## Behavior notes

| Host | Behavior |
| --- | --- |
| macOS | Expected native behavior for this layout. |
| Ubuntu/Linux | May trigger custom user `systemd` keyboard profile behavior. Document details later. |
| Not connected | Built-in laptop keyboard behavior applies instead. |
