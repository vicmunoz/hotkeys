# Amethyst

## Modifiers

| Name | Meaning |
| --- | --- |
| `mod1` | ++alt+shift++ |
| `mod2` | ++alt+shift+ctrl++ / ++meh++ |

## Layouts

| Shortcut | Action |
| --- | --- |
| ++alt+shift+space++ | Cycle layout forward |
| ++alt+shift+a++ | Select tall layout |
| ++alt+shift+s++ | Select bsp layout |
| ++alt+shift+d++ | Select fullscreen layout |
| ++alt+shift+f++ | Select column layout |
| ++alt+shift+g++ | Select floating layout |

## Focus and resize

| Shortcut | Action |
| --- | --- |
| ++alt+shift+h++ | Shrink main pane |
| ++alt+shift+l++ | Expand main pane |
| ++alt+shift+j++ | Focus next window counter-clockwise |
| ++alt+shift+k++ | Focus next window clockwise |
| ++alt+shift+enter++ | Swap focused window with main window |

## Move and swap windows

| Shortcut | Action |
| --- | --- |
| ++meh+h++ | Move focused window to next screen counter-clockwise |
| ++meh+l++ | Move focused window to next screen clockwise |
| ++meh+j++ | Swap focused window to next window counter-clockwise |
| ++meh+k++ | Swap focused window to next window clockwise |
| ++meh+left++ | Move focused window to Space on the left |
| ++meh+right++ | Move focused window to Space on the right |

## State and maintenance

| Shortcut | Action |
| --- | --- |
| ++alt+shift+t++ | Toggle floating state of current focused window |
| ++alt+shift+r++ | Relaunch Amethyst |
