# Muscle memory

The goal is to reuse the same mental model across tools whenever possible.

| Pattern | Meaning |
| --- | --- |
| `h` / `j` / `k` / `l` | Left / down / up / right movement. |
| `H` / `L` | Previous / next horizontal item, often tabs or history. |
| ++hyper++ | Global automation layer. |
| ++meh++ | Secondary automation layer. |
| `leader` or app modifier | Tool-local command layer. |
