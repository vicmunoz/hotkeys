# Modifiers

## Magical keys

| Name | Meaning | Notes |
| --- | --- | --- |
| ++hyper++ | ++alt+shift+ctrl+cmd++ | Main OS/application automation modifier. |
| ++meh++ | ++alt+shift+ctrl++ | Secondary automation modifier. |
| `kitty_mod` | ++hyper++ | Kitty-specific modifier in the current configuration. |
| `mod1` | ++alt+shift++ | Amethyst modifier. |
| `mod2` | ++meh++ | Amethyst modifier. |

## Platform naming

| Symbol | Name |
| --- | --- |
| ++cmd++ | Command / Cmd |
| ++ctrl++ | Control |
| ++alt++ | Option / Alt |
| ++shift++ | Shift |
