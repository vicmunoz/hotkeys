# macOS

## Default bindings

| <div style="width: 200px;">Shortcut</div> | Action | Frequency | Custom | Notes |
| --- | --- | --- | --- |
| ++ctrl++ + ++right++ | Switch to right Space | Daily | No | Mission Control / Spaces. |
| ++ctrl++ + ++left++ | Switch to left Space | Daily | No | Mission Control / Spaces. |
| ++ctrl++ + ++down++ | Open App Exposé | Weekly | No | Shows windows for current app. |
| ++ctrl++ + ++cmd++ + ++space++ | Open emoji keyboard | Rare | No | Character viewer. |
