# macOS

## Default bindings

| Shortcut | Action | Type | Notes |
| --- | --- | --- | --- |
| ++ctrl+right++ | Switch to right Space | Default | Mission Control / Spaces. |
| ++ctrl+left++ | Switch to left Space | Default | Mission Control / Spaces. |
| ++ctrl+down++ | Open App Exposé | Default | Shows windows for current app. |
| ++ctrl+cmd+space++ | Open emoji keyboard | Default | Character viewer. |
