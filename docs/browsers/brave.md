# Brave

Chromium-based browser. Vimium is used for keyboard-driven navigation.

## Native browser shortcuts

| Shortcut | Action | Notes |
| --- | --- | --- |
| ++cmd+d++ | Save bookmark | Chromium/macOS default. |
| ++cmd+t++ | New tab | Chromium/macOS default. |
| ++cmd+w++ | Close tab | Chromium/macOS default. |
| ++cmd+shift+t++ | Reopen closed tab | Chromium/macOS default. |

## Extension layer

See [Vimium for Brave](vimium-brave.md) for keyboard navigation, tab movement, and bookmark shortcuts.
