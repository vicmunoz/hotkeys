# Getting started

## Add shortcuts gradually

Document only the hotkeys you actually use. Prefer small, accurate pages over exhaustive dumps.

## Page structure

Each tool page should include:

1. Context and scope.
2. Modifier definitions used on that page.
3. Workflow-based tables.
4. Raw configuration snippets when useful.
5. Notes about platform, hardware, or conflicts.

## Status values

| Status | Meaning |
| --- | --- |
| Active | Currently used. |
| WIP | Exists but is still being changed. |
| Planned | Desired future mapping. |
| Deprecated | No longer used. |
| Default | Application or OS default. |
| Custom | User-defined mapping. |

## Hardware context

Always record whether a shortcut assumes:

- Moonlander
- Ergodox EZ
- built-in laptop keyboard
- macOS
- Ubuntu/Linux
- browser extension context
- terminal/editor mode
