# Muscle memory

The goal is to reuse the same mental/muscle model across tools whenever possible.

| Pattern | Meaning |
| --- | --- |
| ++h++ / ++j++ / ++k++ / ++l++ | Left / down / up / right movement. |
| ++shift++ + ++h++  / ++shift++ + ++l++ | Previous / next horizontal item, often tabs or history. |
| <kbd>hyper</kbd> | Tool command layer. |
| <kbd>meh/kbd> | Tool command layer. (aka <kbd>mod2</kbd>) |
| ++alt++ + ++shift++ | Tool command layer. (aka <kbd>mod1</kbd>) |
| ++cmd++ + ++ctrl++ | Tool command layer. |
| `leader` or app modifier | Tool command layer. |
