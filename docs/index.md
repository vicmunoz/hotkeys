# hotkeys

A personal documentation site for hotkeys, programmable keyboard behavior, OS-level automation, terminal workflows, editors, browsers, and window management.

## Primary model

Moonlander and Ergodox EZ are the preferred keyboards and both use a macOS-style layout. Linux/Ubuntu is included, but keyboard behavior depends on whether one of those external keyboards is plugged in.

| Context | Behavior |
| --- | --- |
| Moonlander connected | Uses Moonlander layout and related automation. |
| Ergodox connected | Uses Ergodox layout and related automation. |
| Built-in laptop keyboard | Uses the laptop keyboard's native layout. |
| Ubuntu/Linux with external keyboard | May be adjusted by custom user `systemd` services. |

## Main sections

- **Concepts**: Hyper, Meh, notation, and muscle-memory rules.
- **Hardware**: Moonlander, Ergodox EZ, and laptop keyboard behavior.
- **OS**: macOS, Ubuntu/Linux, and OS defaults/customizations.
- **Automation**: Hammerspoon and future systemd keyboard profiles.
- **Terminal**: Kitty, tmux, shells.
- **Editors**: Neovim, Vim, VS Code.
- **Browsers**: Brave and Vimium.
- **Workflows**: navigation, tabs, panes, and windows across tools.
