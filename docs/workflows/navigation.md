# Navigation

| Action | Amethyst | Kitty | Neovim | Vimium |
| --- | --- | --- | --- | --- |
| Previous/left item | <kbd>mod1</kbd> + ++h++ or <kbd>mod2</kbd> + ++h++ depending context | <kbd>hyper</kbd> + ++h++ | ++ctrl++ + ++w++ then ++left++ | ++shift++ + ++h++ for browser history |
| Next/right item | <kbd>mod1</kbd> + ++l++ or <kbd>mod2</kbd> + ++l++ depending context | <kbd>hyper</kbd> + ++l++ | ++ctrl++ + ++w++ then ++right++ | ++shift++ + ++l++ for browser history |
| Previous/down item | <kbd>mod1</kbd> + ++j++ | <kbd>hyper</kbd> + ++j++ | ++ctrl++ + ++w++ then ++down++ | ++shift+j++ previous tab |
| Next/up item | <kbd>mod1</kbd> + ++k++ | <kbd>hyper</kbd> + ++k++ | ++ctrl+w++ then ++up++ | ++shift++ + ++k++ next tab |
